# Netflix Content Analytics Dashboard

## 📊 Project Overview
An interactive Netflix Content Analytics dashboard built using Power BI to analyze movies and TV shows across content type, countries, ratings, genres, and yearly trends.

## 🛠️ Tools Used
- Power BI
- Power Query
- DAX

## 🔍 Key Analysis
- Total Netflix titles
- Movies vs TV Shows
- Top 5 countries
- Content by rating
- Top 10 genres
- Yearly content trends
- Interactive year filtering

## 📈 Dashboard
The dashboard provides an interactive view of Netflix's content distribution and helps identify patterns across content type, geography, ratings, genres, and time.

## 💡 Skills Demonstrated
- Data cleaning and transformation
- Data modeling
- DAX measures
- Data visualization
- Interactive dashboard design
- Business-oriented analysis
